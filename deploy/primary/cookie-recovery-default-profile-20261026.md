# Cookie 自动恢复默认配置（发布准备）

自动 Cookie 恢复忽略账号保存的个人／组织优先选择，沿用 Adobe 当前登录会话的默认配置，不调用资料切换。显式手动登录仍沿用保存的偏好。账号、旧 Cookie、Sub2 关联与 Supply 多 Token 邮箱路由保留。

Sub2 统一执行持久计数：首次失败后再重试两次，共最多三次登录。Okad 每个回调只执行一次协议登录，失败后的五分钟冷却、同邮箱租约和未知结果保护保持。

部署采用现有主服务器增量发布守卫，补丁合并到实际生产源码，保留已部署的取消任务、组织清理、个人组织资料、订阅与 Supply 多 Token 功能。附带的生产补丁与清单用于核对实际运行文件。先在隔离数据库和模拟上游回归，再等待现有任务自然完成后切换，不恢复旧数据库。

尚未上线。验证与实际发布版本在发布后补录。
